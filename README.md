# AI as a Learning Partner

> A documented methodology for using AI to learn, reason, validate, and continuously improve.

## Why this repository exists

Over the past months, I developed a structured workflow for using AI as a learning partner rather than an answer generator.

Instead of asking AI to solve problems for me, I use it to challenge my reasoning, validate assumptions, improve communication, and transform what I learn into reusable assets such as projects, documentation, prompts, and checklists.

This repository documents that methodology through real examples extracted from my learning process in Data Analytics, SQL, Python, professional communication, and career development.

The goal is not to demonstrate what AI can do.

The goal is to demonstrate how I work with AI.
